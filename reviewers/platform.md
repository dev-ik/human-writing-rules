# Platform Reviewer

- [ ] Format fits the platform.
- [ ] Conventions do not override audience needs.
- [ ] Length, markup, links, tags, mentions, metadata, and disclosures fit current platform requirements.
- [ ] CTA and engagement devices are proportionate to the real reader action.
- [ ] Media placement, preview, crop, caption, alt text, and link behavior preserve meaning.
- [ ] The artifact remains understandable when forwarded, excerpted, or viewed outside its original context.

Return each finding with severity (`blocker`, `major`, `minor`, or `note`), location, reason, and smallest useful correction.
