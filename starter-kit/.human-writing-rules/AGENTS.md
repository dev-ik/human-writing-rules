# Project Writing Instructions

1. Read the local config and `core/writing-pipeline.md`.
2. If the user supplied an ordinary conversational request, lead a short intake
   before drafting: extract known answers, ask at most five material questions,
   wait for answers, and repeat only for unresolved material gaps.
3. Do not ask the user to perform research classification, claim-ledger,
   registry, or review work the agent can perform.
4. Resolve language, content type, topic, platform, skill, tone, visual mode,
   reviewers, and transitive dependencies through the registries.
5. Confirm audience, intent, author perspective, constraints, source
   requirements, and risk level from the task, explicit answers, or authorized
   low-risk defaults.
6. Build an evidence map and claim ledger. Never invent facts, sources,
   quotations, events, statistics, product behavior, or personal experience.
7. Do not draft until no required user question remains and the context gate
   passes.
8. Use the selected format and topic foundations. Keep platform conventions
   secondary to reader needs.
9. Make an explicit media decision. Load visual integrity rules before
   generating any selected asset.
10. Run the configured reviewers and resolve blocker and major findings.
11. Return publication copy, visual assets or briefs, source notes, and review
    output as separate sections.
