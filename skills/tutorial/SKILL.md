# Tutorial Skill

Help a defined reader produce and verify a defined result.

## Workflow

1. State the result and prerequisites.
2. Verify versions, environment, permissions, inputs, and safety constraints.
3. Order steps by dependency and keep each step actionable.
4. Explain why a non-obvious step exists.
5. Show expected output or a verification method.
6. Cover common failure modes and safe recovery.
7. Test code, commands, calculations, and links when possible.

Prefer reproducibility over flourish. Do not hide required setup, use ellipses in critical code, or claim success without verification.

Use screenshots only when the interface is stable and date or version them. Use diagrams when they reduce conceptual load; ensure labels and flows match the actual system.
