# Roadmap

## v0.1 — Foundation
- Normative draft profile for scope, pipeline, objects, resolution, review, and benchmarking
- Core pipeline and module resolution
- Independent format, topic, platform, skill, tone, perspective, and visual axes
- Schemas and registries
- RU and EN foundations
- Article and social-post formats
- Generic blog/social plus Telegram, LinkedIn, Habr, and Setka modules
- General, science, technology, entertainment, business, health, finance, culture, lifestyle, education, and travel topics
- Optional illustration integrity and review
- Initial skills, full examples, reviewers, and starter kit

## v0.2 — Validation
- Conformance fixtures for every RFC-0001–0006 MUST requirement
- Full metadata, frontmatter, index, schema, config-reference, and relationship validation
- Offline reference runner for deterministic resolution, pre-draft gates, and run records
- Vendor-neutral adapter protocol and guarded editorial lifecycle transitions
- Shell-free subprocess adapter runtime with bounded IO and explicit env pass-through
- First optional provider adapter for OpenAI Responses and Image APIs, including
  a separately gated visual-production stage and offline raw-response fixtures
- Persisted end-to-end workflow with controlled review stops and separated
  publication, visual, source, review, revision, and audit artifacts
- Versioned, bounded local source snapshots with SHA-256 verification and
  adapter-packet integration
- Deterministic consolidated registry index generation with source revision
  pinning and stale/non-canonical checks
- Evaluator-neutral benchmark runner contract with pinned shared controls,
  source snapshots, arm packets, failure retention, and execution records
- Reviewed example catalog covering all 11 registered topics and all 6
  platform families, with pinned revisions, artifact digests, review contracts,
  and automated coverage checks
- Visual benchmark fixtures and acceptance records for `auto → none`, selected
  assets, PNG and handoff integrity, and expected hard failures
- Pre-stable `0.2.0-draft.1` release candidate with pinned specification and
  registry revisions, compatibility policy, manifest-defined offline gates,
  CI verification, and finalization boundary

## v1.0 — Stable specification
- Active RFC-0001–0006 normative profile and active runtime object set
- Stable 1.x compatibility and identifier lifecycle policy
- Migration guide from `0.2.0-draft`
- Public governance, support, security, conduct, and release contracts
- Internal stability review with an explicit non-independent boundary
- Offline release verification on Python 3.9 and 3.12
- Stable replay configuration for the historical mysticism pilot without
  rewriting its archived provenance
