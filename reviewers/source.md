# Source Reviewer

- [ ] Every material claim is supported, qualified, or removed.
- [ ] Current claims use current sources.
- [ ] Opinion and inference are not presented as fact.
- [ ] Primary and secondary sources play appropriate roles.
- [ ] Dates, versions, populations, jurisdictions, definitions, and units bound the claim correctly.
- [ ] Quotes, paraphrases, captions, visual labels, and derived figures preserve source meaning.
- [ ] Conflicts, unknowns, sponsorships, and material source limitations remain visible.

Return each finding with severity (`blocker`, `major`, `minor`, or `note`), location, affected claim, reason, and smallest useful correction.
