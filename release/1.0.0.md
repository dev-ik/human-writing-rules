# Human Writing Rules 1.0.0

The first stable release defines a vendor-neutral editorial specification for
AI-assisted articles, social posts, and optional illustrations.

## What is stable

- RFC-0001 through RFC-0006 form the active normative `1.0.0` profile.
- All 50 registered runtime objects are active.
- Active RFC, requirement, and object identifiers retain their meaning across
  the 1.x line and are not silently reused.
- Breaking normative, schema, protocol, or identifier changes require a new
  major version and migration notes.

## Included

- RU and EN language foundations;
- article and social-post workflows;
- 11 topic foundations and 6 platform families;
- source-integrity, human-signal, visual-integrity, and review contracts;
- an offline reference runner and guarded editorial lifecycle;
- 200 mapped normative requirements and 10 conformance fixture cases;
- 16 reviewed examples covering every registered topic and platform family;
- evaluator-neutral benchmark and visual-acceptance contracts;
- deterministic registry generation and eight offline release gates.

## Important boundaries

Stable specification status does not claim that every writing engine, or the
bundled reference tooling, has proven full implementation conformance. The
requirements matrix currently contains implementation obligations awaiting
engine-specific evidence.

The stability assessment was internal and not independent. This release does
not include public comparative model-quality results or inter-rater reliability
evidence. These limitations are recorded in
[`release/stability-review.json`](stability-review.json).

## Upgrade

Users of `0.2.0-draft` should follow
[`MIGRATING-TO-1.0.md`](../MIGRATING-TO-1.0.md). Historical audit artifacts
remain pinned to the revisions that produced them.

## Verification

```sh
npm run release:verify
```

The command runs the manifest-defined release gates offline. The optional live
provider adapter remains opt-in and requires credentials supplied through the
environment.
