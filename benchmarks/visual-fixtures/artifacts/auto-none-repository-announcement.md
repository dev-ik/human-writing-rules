# Обновили документацию проекта

В репозитории появились проверяемые примеры для статей и постов, локальные
снимки источников и воспроизводимый benchmark runner. Теперь редакционный
проход можно запустить офлайн и сохранить отдельные публикационные, исходные
и ревью-артефакты.

Иллюстрация для этого короткого служебного сообщения не выбрана: она не
объяснила бы новый механизм и только заняла бы место в ленте.
