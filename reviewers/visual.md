# Visual Reviewer

- [ ] The visual has a defined reader benefit and matches its approved purpose.
- [ ] It is consistent with the final text and evidence map.
- [ ] It does not add unsupported facts, labels, people, events, interfaces, scale, or causal relationships.
- [ ] Generated material is not presented as documentary evidence.
- [ ] Composition, crop, dimensions, file format, and legibility fit the platform.
- [ ] Alt text, caption, credit, provenance, and disclosure are complete when required.
- [ ] Copyright, trademark, likeness, privacy, cultural, and safety constraints are respected.
- [ ] The asset still earns its place after review.

Return each finding with severity (`blocker`, `major`, `minor`, or `note`), location, reason, and smallest useful correction.
