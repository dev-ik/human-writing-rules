# Format Reviewer

- [ ] The selected format matches the amount and complexity of the material.
- [ ] The artifact follows a reader need rather than a forced template.
- [ ] Article sections or social-post units each have a clear function.
- [ ] Required format elements are present and optional elements earn their place.
- [ ] The title, lead, body, conclusion, and metadata make compatible promises.

Return each finding with severity (`blocker`, `major`, `minor`, or `note`), location, reason, and smallest useful correction.
