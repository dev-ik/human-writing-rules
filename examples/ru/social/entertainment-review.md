# Example: RU Generic Social Entertainment Review Method

This example explains review practice without evaluating or quoting a real
work.

## Task framing

- Content type: `social-post`
- Topic: `entertainment`
- Platform: `social`
- Skill: none
- Audience: beginning culture and entertainment writers
- Intent: show how a short review can preserve subjectivity without inventing consensus
- Perspective: editorial
- Artifact form: standalone post
- Visual mode: `auto`
- Sources: `rules/format/social-post/foundation.md`, `rules/topic/entertainment/foundation.md`, `rules/sources/source-integrity.md`

## Resolved modules

`core.writing-pipeline` → `format.social-post.foundation` → `topic.entertainment.foundation` → `platform.social.foundation` → `language.ru.foundation` → source, human-signal, format, topic, platform, visual, and editor reviewers.

## Evidence map

- Verified repository rule: fact, creator statement, marketing, observation, interpretation, opinion, reception, and consensus remain distinct.
- Verified repository rule: evaluation states its criteria and connects a concrete observation to a bounded judgment.
- Verified repository rule: first-person consumption experience cannot be fabricated.
- Editorial inference: an explicit reasoning path lets readers disagree with the evaluation without mistaking it for a factual verdict.
- Unknown: whether the method changes audience response. The post makes no such claim.

## Context gate

Result: `pass`.

The artifact teaches a local editorial method and does not identify a real work,
claim viewing experience, quote copyrighted material, or rely on a protected
asset.

## Content design

- Communication goal: give one compact method for accountable evaluation.
- Reader promise: after reading, a beginning reviewer can separate observation, interpretation, criterion, and judgment.
- Primary claim: subjectivity remains legitimate when the path to the judgment is visible.
- Context floor: the method does not turn opinion into verified fact or consensus.
- Ending: bounded explanation without a recommendation CTA.

## Final artifact

Субъективность не мешает короткой рецензии. Проблема начинается, когда мнение маскируется под общий вердикт.

Проверить оценку можно по простой цепочке:

**наблюдение → интерпретация → критерий → вывод**

Например, сначала автор описывает конкретный приём в произведении. Затем объясняет, как понимает его функцию. Называет критерий — ритм, структуру, исполнение, работу с жанром — и только после этого формулирует оценку.

Читатель может не согласиться с интерпретацией или критерием. Но он видит, откуда взялся вывод.

Фразы вроде «все зрители считают» требуют отдельного основания. Личное впечатление остаётся личным — и от этого не становится менее ценным.

## Media decision

Decision: no visual.

The post does not concern a selected work and has no rights-cleared promotional
asset. A generated character, performer likeness, scene, poster, or style
imitation would create unsupported identity or rights implications. A generic
decorative cover would not improve the reasoning chain.
