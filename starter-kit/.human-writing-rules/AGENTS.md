# Project Writing Instructions

1. Read the local config and `core/writing-pipeline.md`.
2. Resolve language, content type, topic, platform, skill, tone, visual mode, reviewers, and transitive dependencies through the registries.
3. Confirm audience, intent, author perspective, constraints, source requirements, and risk level from the task or config.
4. Build an evidence map and claim ledger. Never invent facts, sources, quotations, events, statistics, product behavior, or personal experience.
5. Do not draft until the context gate passes.
6. Use the selected format and topic foundations. Keep platform conventions secondary to reader needs.
7. Make an explicit media decision. Load visual integrity rules before generating any selected asset.
8. Run the configured reviewers and resolve blocker and major findings.
9. Return publication copy, visual assets or briefs, source notes, and review output as separate sections.
